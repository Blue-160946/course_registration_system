# ระบบลงทะเบียนเรียน (Course Registration System)

เว็บแอปพลิเคชันสำหรับจัดการรายวิชา กลุ่มเรียน ตารางเรียน การลงทะเบียน และประวัติการชำระเงิน พัฒนาด้วย **Django 5.2** และ **PostgreSQL**

## ระบบทำอะไรได้บ้าง

ระบบแบ่งการใช้งานเป็น 2 บทบาทหลัก คือ **เจ้าหน้าที่** และ **นักศึกษา** โดยมีฟังก์ชันดังนี้

| บทบาท | ฟังก์ชัน |
| --- | --- |
| เจ้าหน้าที่ | จัดการข้อมูลคณะ ภาควิชา สาขา ห้องเรียน และภาคการศึกษา |
| เจ้าหน้าที่ | เพิ่ม แก้ไข และลบรายวิชา รวมถึงกำหนดหน่วยกิต ค่าธรรมเนียม และสถานะเปิดรายวิชา |
| เจ้าหน้าที่ | สร้างกลุ่มเรียน (Section) กำหนดอาจารย์ผู้สอน ห้องเรียน จำนวนรับ และคาบเรียน |
| เจ้าหน้าที่ | ดูรายชื่อนักศึกษา รายละเอียดรายบุคคล และประวัติการชำระเงิน |
| นักศึกษา | ค้นหารายวิชาที่เปิดในภาคเรียนปัจจุบันด้วยรหัสวิชาหรือชื่อวิชา |
| นักศึกษา | ลงทะเบียนเรียน โดยระบบตรวจสอบว่ารายวิชาเปิดอยู่ อยู่ในภาคเรียนปัจจุบัน ลงทะเบียนซ้ำ หรือเต็มแล้วหรือไม่ |
| นักศึกษา | ดูตารางเรียนภาคการศึกษาปัจจุบัน ดาวน์โหลดเป็น PDF และดูประวัติการชำระเงิน |

สิทธิ์การเข้าถึงถูกตรวจสอบในระบบ: หน้าจัดการเปิดให้เฉพาะเจ้าหน้าที่ ส่วนหน้าลงทะเบียน ตารางเรียน และประวัติการชำระเงินเปิดให้เฉพาะผู้ใช้ที่เป็นนักศึกษา

## สิ่งที่ต้องเตรียม

- Git
- Python 3.10 ขึ้นไป (แนะนำ Python 3.12 หรือ 3.13)
- PostgreSQL 14 ขึ้นไป และเครื่องมือ `psql`

ตรวจสอบเวอร์ชันได้ด้วยคำสั่ง:

```bash
python --version
psql --version
```

> บน Windows หาก `python` ใช้งานไม่ได้ ให้ใช้ `py` แทนในทุกคำสั่งด้านล่าง

## ติดตั้งและรันโปรเจกต์

### 1. ดาวน์โหลดโค้ด

```bash
git clone <repository-url>
cd course_registration_system-1
```

หากได้รับโฟลเดอร์โปรเจกต์มาอยู่แล้ว ให้เปิด Terminal/PowerShell ที่โฟลเดอร์นี้ได้เลย

### 2. สร้างและเปิดใช้ virtual environment

**Windows PowerShell**

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

หาก PowerShell แจ้งว่าไม่อนุญาตให้รันสคริปต์ ให้รันคำสั่งนี้หนึ่งครั้งในหน้าต่าง PowerShell เดิม แล้วสั่ง activate อีกครั้ง:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

**macOS / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. ติดตั้ง Python packages

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. สร้างฐานข้อมูล PostgreSQL

เข้าสู่ PostgreSQL ด้วยผู้ใช้ที่มีสิทธิ์สร้างฐานข้อมูล แล้วสร้างฐานข้อมูลและผู้ใช้สำหรับโปรเจกต์:

```sql
CREATE USER course_registration_user WITH PASSWORD 'ตั้งรหัสผ่านที่คาดเดายาก';
CREATE DATABASE course_registration_system OWNER course_registration_user;
```

### 5. ตั้งค่าตัวแปรแวดล้อม

คัดลอกไฟล์ตัวอย่างเป็น `.env`:

**Windows PowerShell**

```powershell
Copy-Item .env.example .env
```

**macOS / Linux**

```bash
cp .env.example .env
```

จากนั้นแก้ไขไฟล์ `.env` ให้ตรงกับฐานข้อมูลของเครื่อง เช่น:

```env
SECRET_KEY=replace-with-a-long-random-secret-key
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1
PAYMENT_GATEWAY_MODE=disabled

NAME_DB=course_registration_system
USER_DB=course_registration_user
PASSWORD_DB=ตั้งรหัสผ่านเดียวกับที่สร้างใน PostgreSQL
HOST_DB=localhost
PORT_DB=5432
```

สามารถสร้างค่า `SECRET_KEY` ใหม่ได้ด้วย:

```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

อย่าส่งไฟล์ `.env` ขึ้น Git หรือเผยแพร่รหัสผ่านและ `SECRET_KEY`

### 6. สร้างตารางในฐานข้อมูล

```bash
python manage.py migrate
```

### 7. สร้างข้อมูลสาธิต (แนะนำสำหรับการเรียนรู้)

```bash
python manage.py seed_mock_data
```

คำสั่งนี้สร้างคณะ ภาควิชา สาขา รายวิชา กลุ่มเรียน ตารางเรียน ผู้ใช้ และรายการชำระเงินตัวอย่าง โดยรันซ้ำได้อย่างปลอดภัย

ข้อมูลสาธิตสร้างภาคเรียน 1/2569 ระหว่าง **8 มิถุนายน – 4 ตุลาคม 2026** ดังนั้นฟังก์ชันลงทะเบียนจะแสดงรายวิชาได้เมื่อวันปัจจุบันอยู่ในช่วงนี้ หากทดลองใช้นอกช่วงเวลา ให้เข้าสู่ระบบด้วยบัญชีเจ้าหน้าที่แล้วแก้ไขวันเริ่มและวันสิ้นสุดของภาคเรียนที่เมนูข้อมูลหลัก

### 8. เริ่มเซิร์ฟเวอร์

```bash
python manage.py runserver
```

เปิดเบราว์เซอร์ที่ [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## วิธีทดลองใช้งานระบบ

### เส้นทางของเจ้าหน้าที่

1. เข้าสู่ระบบด้วย `registrar` และรหัสผ่าน `DemoPass123!` ระบบจะพาไปหน้าจัดการรายวิชา
2. ไปที่ `/manage/courses/master-data/` เพื่อตรวจสอบหรือเพิ่มข้อมูลหลัก ได้แก่ คณะ ภาควิชา สาขา ห้องเรียน และภาคการศึกษา ก่อนสร้างรายวิชาหรือกลุ่มเรียนใหม่
3. ไปที่ `/manage/courses/` เพื่อเพิ่มหรือแก้ไขรายวิชา กดเข้าไปในรายวิชาเพื่อจัดการกลุ่มเรียน
4. ในกลุ่มเรียน ให้กำหนดหมายเลขกลุ่ม จำนวนรับ ห้องเรียน และผู้สอน จากนั้นเพิ่มคาบเรียนให้ครบตามตารางสอน
5. ไปที่ `/users/students/` เพื่อดูรายชื่อนักศึกษา และกดชื่อของนักศึกษาเพื่อดูข้อมูลและประวัติการชำระเงิน

### เส้นทางของนักศึกษา

1. ออกจากระบบก่อน หากกำลังใช้บัญชีเจ้าหน้าที่ แล้วเข้าสู่ระบบด้วยบัญชี `student_66000001` (หรือบัญชีนักศึกษาอื่นในตารางด้านบน)
2. ระบบจะพาไปที่ `/manage/courses/register/` ซึ่งแสดงกลุ่มเรียนของภาคเรียนปัจจุบัน ใช้ช่องค้นหาเพื่อค้นหาจากรหัสหรือชื่อวิชา
3. เลือกกลุ่มเรียนที่ต้องการและกดลงทะเบียน ระบบจะป้องกันการลงทะเบียนซ้ำ กลุ่มเรียนเต็ม หรือรายวิชาที่ไม่เปิดแล้ว
4. เปิด `/manage/courses/my-schedule/` เพื่อตรวจสอบตารางเรียน และดาวน์โหลดตารางในรูปแบบ PDF ได้จากหน้านี้
5. เปิด `/users/payment-history/` เพื่อดูประวัติรายการชำระเงินของตนเอง

> รายวิชาที่มีค่าธรรมเนียมจะลงทะเบียนได้ในเครื่องพัฒนาเมื่อกำหนด `PAYMENT_GATEWAY_MODE=fake` ตามหัวข้อการชำระเงินด้านล่าง ส่วนรายวิชาค่าธรรมเนียม 0 บาทลงทะเบียนได้โดยไม่ต้องเปิดโหมดนี้

## การชำระเงินในเครื่องพัฒนา

ค่าเริ่มต้น `PAYMENT_GATEWAY_MODE=disabled` จะไม่เรียกบริการชำระเงินจริง สำหรับการสาธิต flow การชำระเงินสามารถตั้งค่าเป็น:

```env
PAYMENT_GATEWAY_MODE=fake
```

โหมด `fake` มีไว้สำหรับการพัฒนาและการทดสอบเท่านั้น ห้ามนำไปใช้กับระบบจริง

## แก้ปัญหาเบื้องต้น

**เชื่อมต่อ PostgreSQL ไม่ได้**  
ตรวจสอบว่า PostgreSQL service ทำงานอยู่ และค่า `NAME_DB`, `USER_DB`, `PASSWORD_DB`, `HOST_DB`, `PORT_DB` ใน `.env` ถูกต้อง

**พบ `ModuleNotFoundError`**  
ตรวจสอบว่าเปิดใช้ virtual environment แล้ว และรัน `pip install -r requirements.txt` สำเร็จ

**พบ `SECRET_KEY` หรือ environment variable error**  
ตรวจสอบว่ามีไฟล์ `.env` อยู่ที่โฟลเดอร์เดียวกับ `manage.py` และกำหนดค่าครบตาม `.env.example`

**พอร์ต 8000 ถูกใช้งานอยู่**  
รันบนพอร์ตอื่น เช่น:

```bash
python manage.py runserver 8001
```

## หมายเหตุสำหรับการนำขึ้นใช้งานจริง

คู่มือนี้มุ่งสำหรับการรันในเครื่องเพื่อการเรียนรู้เท่านั้น ก่อน deploy จริง ให้ตั้ง `DEBUG=False`, ใช้ `SECRET_KEY` ที่ปลอดภัย, จำกัด `ALLOWED_HOSTS`, เก็บรหัสผ่านใน secret manager และตั้งค่าฐานข้อมูล/การชำระเงินสำหรับสภาพแวดล้อม production โดยเฉพาะ
